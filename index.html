✓
MP rash
พบบ่อยสุด
ผื่นราบและตุ่มนูนสีแดงผสมกัน กระจาย 2 ข้างสมมาตร
✓
Urticaria (ลมพิษ)
ควรระวัง
ผื่นนูนแดง ขอบชัด คันมาก ยุบหายเองภายใน 24 ชม.
✓
Angioedema
ฉุกเฉิน
บวมลึกใต้ผิวหนัง บริเวณริมฝีปาก เปลือกตา ใบหน้า
✓
Fixed Drug Eruption
ทิ้งรอยดำ
ผื่นกลม/รี สีคล้ำ เกิดซ้ำที่ตำแหน่งเดิมเมื่อได้ยาซ้ำ
✓
Exfoliative dermatitis
รุนแรง
ผิวหนังแดงลอกเป็นขุยทั่วร่างกาย > 90%
✓
SJS / TEN
ฉุกเฉินวิกฤต
ผื่นรุนแรง ผิวหนังพุพอง ลอกหลุด และมีแผลเยื่อบุ

📝 4. แบบประเมิน Naranjo Algorithm
กรุณาแตะเลือกคำตอบให้ครบทั้ง 10 ข้อ
1. มีรายงานการแพ้ยาชนิดนี้มาก่อนหรือไม่?
2. อาการเกิดขึ้นหลังจากได้รับยาที่สงสัยหรือไม่?
3. อาการดีขึ้นเมื่อหยุดยาหรือให้ยาต้านพิษหรือไม่?
4. อาการกลับมาอีกเมื่อให้ยาซ้ำหรือไม่ (Rechallenge)?
5. มีสาเหตุอื่นที่อาจทำให้เกิดอาการนี้ได้หรือไม่?
6. อาการกลับมาเมื่อให้ยาหลอกหรือไม่ (Placebo)?
7. ตรวจพบยาในเลือดหรือของเหลวในระดับที่เป็นพิษ?
8. อาการรุนแรงขึ้นเมื่อเพิ่มยา หรือเบาลงเมื่อลดยา?
9. ผู้ป่วยเคยมีอาการคล้ายกันกับยานี้หรือยาคล้ายกัน?
10. มีหลักฐานภววิสัยอื่นยืนยันการแพ้ยา (Objective)?
🎯 ผลการประเมินการแพ้ยา
เกณฑ์คะแนน Naranjo Algorithm:
≥9: ใช่แน่ (Definite) | 5-8: น่าจะใช่ (Probable)
1-4: อาจจะใช่ (Possible) | ≤0: ไม่น่าจะใช่ (Doubtful)
